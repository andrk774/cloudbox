# CloudBox для Android и iOS

Мобильное приложение CloudBox на Flutter: файлы в облаке и автозагрузка фото с телефона.

## Возможности

- **Вход по адресу сервера и паролю приложения.** Пароль приложения создаётся на сайте: *Настройки → Пароли приложений*. Он работает и с двухфакторной аутентификацией, и его можно отозвать, не меняя основной пароль. На телефоне пароль хранится в защищённом хранилище системы: Keystore на Android, Keychain на iOS.
- **Файлы:**
  - папки, миниатюры фото, видео и PDF;
  - поиск по имени и содержимому;
  - открытие файла в подходящем приложении телефона;
  - загрузка с телефона (большие файлы — частями по 8 МБ с продолжением после обрыва);
  - новая папка, переименование, удаление в корзину.
- **Автозагрузка фото и видео** в папку «Фото/Камера/<год>». Запускается при открытии приложения и по кнопке в настройках. Можно выбрать, загружать только новые снимки или всю галерею. Уже загруженное повторно не отправляется. Файл с таким же именем не перезаписывается, а сохраняется под новым именем.
- **Зашифрованные (E2E) папки** показываются с замком. Открыть их пока можно только в веб-версии.

## Ограничения этой версии

- **Нет фоновой автозагрузки при закрытом приложении.** Снимки загружаются при следующем открытии.
- **Нет расшифровки E2E-папок, чата и почты.** Они доступны в веб-версии, которую можно установить на телефон как PWA.
- **Нет офлайн-доступа к файлам.**

## Сборка

Нужен Flutter (проверено на 3.47.7) и Android SDK.

```bash
cd mobile
flutter pub get
flutter test                         # unit и виджет-тесты
flutter build apk --release          # build/app/outputs/flutter-apk/app-release.apk
```

Готовый APK для каждого изменения собирает GitHub Actions (`.github/workflows/mobile.yml`, артефакт `cloudbox-android`). Там же идёт живой тест API-клиента против настоящего сервера:

```bash
CB_URL=http://127.0.0.1:8080 CB_USER=… CB_PASS=<пароль приложения> flutter test test/live_test.dart
```

**Подпись.** Release-сборка подписывается отладочным ключом: этого достаточно, чтобы установить APK на свой телефон. Для публикации в Google Play нужен свой ключ, см. [документацию Flutter](https://docs.flutter.dev/deployment/android#sign-the-app).

**iOS.** Сборка (`flutter build ipa`) возможна только на Mac с Xcode. Код и настройки для iOS в проекте есть, но на iOS приложение не проверялось.

## Без HTTPS

На Android и в локальной сети на iOS приложение разрешает подключение по `http://`, потому что CloudBox часто стоит дома без сертификата. Без HTTPS пароль и файлы идут по сети открытым текстом, и приложение предупреждает об этом при входе. Для доступа из интернета используйте HTTPS: Caddy из `docker-compose` настраивает его автоматически.
